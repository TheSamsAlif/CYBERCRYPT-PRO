🏗 Project Architecture

One cryptographic core, two frontends — a native desktop app and a serverless web app sharing the exact same engine.

🌐 Web Frontend — Vercel
index.html is the premium glass chat UI you are using right now — sidebar, composer and animated layer steps, running fully in your browser. Encrypt / Decrypt requests go to two Vercel serverless functions: api/encrypt.py and api/decrypt.py (Flask), which import the same core engine and return JSON results.
🖥 Desktop Frontend — CustomTkinter
main.py launches the native window (cybercrypt/app.py). Every screen lives in cybercrypt/ui/screens/ — dashboard, encrypt, decrypt, analysis, architecture, guide and about — built with animated glass widgets, tooltips and a dark/light theme engine.
🧠 Core Engine — cybercrypt/core
Pure Python with zero UI dependencies, so both frontends call the identical logic:
caesar_cipher.py → vigenere_cipher.py → random_layer.py
Unified by engine.py, while alphabet.py defines the 128-character printable alphabet every layer operates on.
📡 Web Request Flow
You type → fetch /api/encrypt → Flask function → engine.encrypt_text() → JSON steps → animated result
Nothing is stored on any server — your text exists only in the request, the response and your screen.

⚙️ Working Method

How your message travels through three classical cipher layers — and how it comes back.

1
Input & Keys You type a message and provide three keys: a Caesar shift number, a Vigenère keyword and a numeric XOR seed. The 🎲 button can generate all three randomly.
2
Layer 1 · Caesar Cipher Every character is shifted forward by your shift number, wrapping inside the 128-character alphabet. E(x) = (x + shift) mod 128
3
Layer 2 · Vigenère Cipher A repeating keyword applies a different offset to each character, so the same letter encrypts differently every time. E(x) = (x + key[i]) mod 128
4
Layer 3 · Random XOR Your seed drives a pseudo-random keystream that is XOR-ed with the text — impossible to guess without the exact seed. E(x) = x ⊕ stream(i)
5
Cipher Text The final output is unreadable and safe to share. Each intermediate layer result is shown step by step in the chat.
6
Decryption — Exact Reverse With the same three keys, the layers are peeled off in reverse order: XOR → Vigenère → Caesar → your original text. D(x) = D₁(D₂(D₃(cipher)))
